# Student Access Portal

A responsive student portal demo built with plain HTML, CSS, and JavaScript. It is designed to open directly in Visual Studio Code and can be hosted as a static website.

## Features

- Demo login screen
- Student dashboard with summary cards
- Student profile
- Attendance overview
- Examination results
- Weekly timetable
- College announcements
- Responsive layout for desktop and mobile
- Sidebar navigation and logout

## Project structure

```text
student-access-portal/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
├── .gitignore
└── README.md
```

## Run locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension.
4. Use the demo credentials below.

## Demo credentials

- **Student ID:** `student`
- **Password:** `1234`

## Important

This is a front-end demonstration only. The login credentials and academic information are sample data stored in client-side code. Do not use this login for real student accounts or sensitive information. A production portal needs a secure backend, database, server-side authentication, and appropriate access controls.
